# SafeCheck Pro\n\nResponsive password and URL safety toolkit. Includes local password-strength feedback, cryptographically secure password generation, Have I Been Pwned k-anonymity range lookup, and URL warning heuristics.\n\n## Deploy\nImport this repository into Vercel using the repository root. No build command or environment variables are required.\n\n## Limitations\nURL scores are heuristic warnings, not proof that a site is safe or malicious. A low score does not guarantee safety. Password strength checks run in the browser; breach lookup sends only a five-character SHA-1 prefix to the API endpoint, not the full hash to the provider.
