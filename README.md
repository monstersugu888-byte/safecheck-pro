# SafeCheck Pro\n\nResponsive digital-safety toolkit: password strength feedback, cryptographically secure password generation, Have I Been Pwned range lookup, and URL warning heuristics.\n\n## Deploy\nImport this repository into Vercel using the repository root. No build command or environment variables are required. API endpoints are in the `api/` directory.\n\n## Limitations\nThe URL scan is heuristic, not proof that a website is safe or malicious. Password checks run locally. Breach lookup sends only the first five characters of a SHA-1 hash to the provider through the API. Do not use a real password in a site you do not trust.
